# Oluwaseun (Bolu) Adalemo — IT Systems & Security Portfolio (`badalemo.github.io`)

This repository hosts my technical portfolio for the **IT Systems Management and Security** diploma program at **Nova Scotia Community College (NSCC)**, including my **PPIT 2 Task C: Portfolio Work Sample**.

## Repository Structure

* `/index.html` & `/style.css` — **Main Portfolio & PPIT Task C Work Sample**: Detailed case study on Enterprise Multi-VLAN Network Design, OSPF Dynamic Routing, VLSM Subnetting, and Extended Access Control List (ACL) Perimeter Security.
* `/PrivacyPal/` — **PrivacyPal Web Application**: An interactive cybersecurity education tool covering phishing detection, password strength evaluation, data privacy, and social engineering defense.
* `/interactive resume/` — **Interactive Resume**: Full-stack development, systems administration, and technical experience showcase.

## How to Export for Brightspace (PPIT Task C Requirement)
Because the assignment requires an uncompressed, PC-compatible document placed in the Brightspace assignment folder:
1. Open `index.html` in any browser (or visit `https://badalemo.github.io`).
2. Press `Ctrl + P` (Windows/Linux) or `Cmd + P` (Mac) and select **Save as PDF** (the print stylesheet automatically formats the page into a clean, printer-friendly report), **or** copy the structured sections directly into Microsoft Word (`.docx`) along with your Packet Tracer topology screenshot.
